Assignment 6 - Database Cursors

Assignment 6 – Cursors

Objectives

Use a cursor in a stored procedure

One of the most useful tools in stored procedures is cursors. You need to know how to create them and iterate through them in a stored procedure.

Assignment

This is all about learning to use one of the primary tools that are often used in stored procedures – cursors.  You will need to know what they are and how to use them. The good news is they are not that complex.

Default Assignment

Please note that any example that you come up with that shows (1) creating a cursor, (2) iterating using a cursor, (3) row by row operations using a cursor – will satisfy this assignment. I am providing an example that would require a cursor so that if you do NOT have some example to use, you at least have something for the assignment.

You will be creating a simple stored procedure that uses one or more Cursors  – name the stored procedure sp_DisplayCollege. You may develop multiple stored procedures to achieve this. You are going to use the data from Assignment 2

The stored procedure should accept a single argument – the name of a College, it will need to find all Colleges that match the name (including partial match).

For each College that matches the criteria – we are going to prepare a data report. This report will be a comparison of the college on each of these fields as compared to the average of the value of the field.

Information

The video and weekly reading on cursors should be sufficient for this assignment. I recommend writing multiple stored procedures to achieve the report. You can call a stored procedure from within a stored procedure.  First I would create a stored procedure that takes the input (Name of College) and creates a cursor from this. I would then call other stored procedures and stored functions to perform the queries associated with the report. This will allow you to divide and conquer each of the pieces of the report.

5 hours to cover cursors and write all the necessary stored procedures.
