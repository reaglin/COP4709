Graded Discussion 10

Below are the functions supported by the major databases for full text indexing. For your assignment you did an example of a full text index in SQL Server using the functions available in SQL Server. Give an example of how you would perform just the same search using a full text index in any other database. 

Full-Text Search Support by Database System

All major databases in the list support full-text indexing, but with different implementation approaches and syntax:

Oracle

Oracle Text (formerly Oracle InterMedia) provides full-text search capabilities:

Function/Feature Description
CONTAINS Main operator for full-text queries
SCORE Returns relevance ranking
CTX_QUERY.PARSE Parses and returns query string
CTX_DOC.SNIPPET Generates highlighted snippet of search results
CTX_DOC.HIGHLIGHT Highlights terms in documents
MATCH_SCORE Returns relevance score for ranking
ABOUT Performs concept-based searching
WITHIN Searches within a specific section
NEAR Proximity searching
FUZZY Fuzzy matching for similar terms
SOUNDEX Phonetic matching
STEMMING Word stemming for variants
WILDCARDS Pattern matching with wildcards
THESAURUS Thesaurus-based expansion

SQL Server

SQL Server Full-Text Search:

Function/Feature Description
CONTAINS Searches for words, phrases, or proximity terms
CONTAINSTABLE Returns a table of matches with rank
FREETEXT Searches for meaning, not exact words
FREETEXTTABLE Returns a table with ranked results for meaning-based search
SEMANTICSIMILARITYTABLE Finds semantically similar documents (newer versions)
SEMANTICKEYPHRASETABLE Extracts key phrases (newer versions)
FULLTEXTCATALOG Creates full-text catalogs
FULLTEXTINDEX Creates full-text indexes
STOPLIST Defines words to ignore in searches
THESAURUS Custom synonyms for search terms
LANGUAGE Language-specific analysis

MySQL

MySQL Full-Text Search:

Function/Feature Description
MATCH ... AGAINST Basic full-text search function
IN NATURAL LANGUAGE MODE Default search mode
IN BOOLEAN MODE Search with Boolean operators
WITH QUERY EXPANSION Automatic query expansion
IN NATURAL LANGUAGE MODE WITH QUERY EXPANSION Combined natural language and expansion
FULLTEXT INDEX Creates full-text indexes
INNODB_FT_* Configuration variables for InnoDB full-text
ngram N-gram parser for CJK languages
MeCab Parser for Japanese full-text indexing

PostgreSQL

PostgreSQL Full-Text Search:

Function/Feature Description
to_tsvector Converts text to searchable tokens
to_tsquery Converts search string to query format
plainto_tsquery Converts plain text to query without operators
phraseto_tsquery Converts phrases to query (newer versions)
websearch_to_tsquery Web search style query conversion (newer versions)
@@ Text search match operator
ts_rank Calculates relevance ranking
ts_rank_cd Cover density ranking algorithm
ts_headline Generates highlighted excerpt
GIN Generalized Inverted Index type
GiST Generalized Search Tree index type
tsvector_update_trigger Trigger to maintain search vectors
dict_* Dictionary functions for text normalization
ts_lexize Test dictionary operation
ts_parse Test parser operation
ts_debug Test configuration operation

IBM Db2

IBM Db2 Text Search:

Function/Feature Description
CONTAINS Performs text search
SCORE Returns relevance score
DB2TEXT.CATSEARCH Catalog-based text search
DB2TEXT.CONTAINS Searches document text
DB2TEXT.REFINE Refines search results
DB2TEXT.FINDFILE Searches for filenames
TEXT INDEX Creates text search indexes
UPDATE INDEX Updates text search indexes
LINGUISTIC INDEX Language-specific text indexing
SYNONYM DICTIONARIES Custom synonyms
STOP WORD DICTIONARIES Custom stop words
