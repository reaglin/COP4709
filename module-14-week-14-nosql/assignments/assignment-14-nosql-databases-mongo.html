Assignment 14 - NoSQL Databases (Mongo)

Objective

  1. Create and use a MongoDB NoSQL database.
  2. Describe  the correct situational uses of NoSQL databases

Assignment

  1. Create either a local copy  of MongoDB or an instance in the cloud.
  2. Using this instance use any data set (I recommend the restaurant data) to create at least one Collection with multiple Documents (similar to one table with multiple records).
  3. Populate the collection with the data selected in (2)
  4. For the assignment you must demonstrate demonstrate queries and results using the operators IN, AND and OR.
  5. Your report should demonstrate these queries and results. Your report should also document the limitations of NoSQL databases and the proper situations for when you should use NoSQL databases. 
  6. Follow reporting requirements as outlined in "Guide to Writing Good Reports "
