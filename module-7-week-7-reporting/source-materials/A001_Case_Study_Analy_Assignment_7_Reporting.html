Assignment 7 – Generating Reports

Objectives

Create a database report (using Report Builder 3 ) – you may use Crystal Reports or another reporting tool ( the use of Visual Studio tools and/or Crystal Reports designer is not covered in this course).

In the database world, you will be asked to create reports. There are many ways to create reports, but you should have a basic understanding of the use of database reporting tools and how to organize the data and use these tools. Nearly all tools for database reporting operate in a similar fashion. 

Assignment

For this assignment, you are going to create a report using Report Builder. Use the current version available from Microsoft this tool is like most report builders (like Crystal Reports) – but it is free and it works well with SQL Server so we will use it.
