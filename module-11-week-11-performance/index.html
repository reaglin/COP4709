Module 11 (Week 11) - Performance

This module turns to SQL Server query performance: measuring logical and physical reads with SET STATISTICS IO and TIME to establish a pre-tuning baseline, querying Dynamic Management Views and Query Store for expensive queries, wait statistics, index usage and file I/O latency, and reading execution plans to distinguish index seeks, scans, key lookups and join operators. Students build clustered, non-clustered, covering (INCLUDE), filtered and columnstore indexes, weigh the read/write trade-off along with fragmentation, REORGANIZE versus REBUILD and statistics upkeep, and rewrite queries for SARGability while avoiding SELECT *, implicit conversions and poor EXISTS/IN/JOIN choices. The assignment applies this to the housing database with Category and Code lookup tables, profiling the Assignment 8 aggregation query, selecting and justifying an optimization — indexing, denormalization, summary tables or indexed views — and reporting pre- and post-optimization timings.
